# V6.3 Changes

- PostgreSQL connection screen and Settings connection editor: host/server IP, port, database, username, password and SSL.
- LAN/multi-PC server binding (`0.0.0.0`) with shared PostgreSQL support.
- Full SQL Backup and Restore in Settings. Restore creates a pre-restore safety backup first.
- Fresh installs no longer insert demo/sample products, suppliers, customers, transactions or repair records.
- Product Delete now moves products to Recycle Bin even when stock exists; stock/history are preserved and the product can be restored.
- Auto recycle cleanup never archives a deleted product while its stock is above zero.
- Admin user control now includes module access plus granular action permissions.
- Repair Service pricing split into Service Fee + Parts Cost with automatic total and invoice breakdown.
- Inventory summary cards and the overall UI are more compact, aligned and no-wrap for management tables.
- GitHub-ready cleanup: node_modules and local DB credentials are excluded, stale V4-V6 docs/demo scripts removed.
